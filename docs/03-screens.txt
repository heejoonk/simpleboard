# 화면 목록

화면 배치는 docs/wireframes/ 의 이미지(excalidraw)를 따르고,
동작·조건·문구는 이 문서를 따른다. 둘이 다르면 구현 전에 질문한다.

| ID | 화면명 | URL | 권한 | 와이어프레임 | 관련 기능 |
|---|---|---|---|---|---|
| S-01 | 게시글 목록 (메인) | /, /posts | 전체 | wireframes/S-01-post-list.excalidraw.png | F-03 |
| S-02 | 회원가입 | /signup | GUEST | wireframes/S-02-signup.excalidraw.png | F-01 |
| S-03 | 로그인 | /login | GUEST | wireframes/S-03-login.excalidraw.png | F-02 |
| S-04 | 게시글 상세 + 댓글 | /posts/{id} | 전체 | wireframes/S-04-post-detail.excalidraw.png | F-04, F-07, F-08, F-09 |
| S-05 | 게시글 작성 | /posts/new | USER | wireframes/S-05-post-form.excalidraw.png | F-05 |
| S-06 | 게시글 수정 | /posts/{id}/edit | 작성자 | (S-05와 같은 화면) | F-06 |
| E-01 | 에러 페이지 (403/404/500) | - | 전체 | - | 공통 |

와이어프레임 파일이 아직 없으면 아래 텍스트 스케치를 기준으로 한다.

## 공통 레이아웃 (Thymeleaf layout fragment)
- 헤더: 좌측 로고 "SimpleBoard"(클릭 시 /), 우측 로그인 상태 영역
  - 비로그인: [로그인] [회원가입]
  - 로그인: {닉네임}님 [로그아웃]   ← 로그아웃은 POST form 버튼 (링크 아님)
  - 로그인 여부는 Model의 loginMember 속성으로 판단 (LoginMemberModelAdvice가 모든 화면에 넣어 줌)
- 본문: 가운데 정렬, 최대 너비 900px
- 푸터: "© 2026 SimpleBoard" 한 줄

## S-01 게시글 목록
+---------------------------------------------------+
| SimpleBoard                     홍길동님 [로그아웃] |
+---------------------------------------------------+
| 게시판                                    [글쓰기] |   ← 로그인 시에만
| +----+------------------+-------+-------+------+ |
| |번호| 제목 [댓글수]      | 작성자 | 작성일 | 조회 | |
| +----+------------------+-------+-------+------+ |
| | 12 | 첫 글입니다 [3]    | 홍길동 |10-20  |  25  | |
| +----+------------------+-------+-------+------+ |
|              < 1 2 3 4 5 >                         |
+---------------------------------------------------+
- 제목 클릭 → S-04
- 댓글 수가 0이면 [0]은 표시하지 않는다
- 글이 없으면 표 대신 "등록된 글이 없습니다"

## S-02 회원가입
- 입력: 이메일, 비밀번호, 비밀번호 확인, 닉네임
- 각 입력란 아래 오류 메시지 영역 (빨간 글씨)
- 버튼: [가입하기]
- 하단 링크: "이미 계정이 있나요? 로그인"

## S-03 로그인
- 입력: 이메일, 비밀번호
- 숨은 필드: redirectURL (쿼리 파라미터로 받은 값을 그대로 담아 POST로 전달)
- 버튼: [로그인]
- 상단 메시지 영역
  - 로그인 실패 (폼 재렌더링) → "이메일 또는 비밀번호가 올바르지 않습니다"
  - /login?joined            → "가입이 완료되었습니다. 로그인해주세요"
  - redirectURL이 있을 때     → "로그인이 필요한 페이지입니다"
- 하단 링크: "계정이 없나요? 회원가입"

## S-04 게시글 상세
+---------------------------------------------------+
| 첫 글입니다                                         |
| 홍길동 · 2026-10-20 14:30 · 조회 25                 |
| (수정됨 2026-10-20 15:00)        [수정] [삭제]      |   ← 작성자만
+---------------------------------------------------+
| 본문 내용 ...                                      |
+---------------------------------------------------+
| 댓글 3                                             |
|  김철수 · 10-20 14:40                       [삭제]  |   ← 댓글 작성자만
|  좋은 글이네요                                      |
| +-------------------------------------+ [등록]    |   ← 로그인 시
| +-------------------------------------+           |
| [목록으로]                                         |
+---------------------------------------------------+
- [삭제]는 confirm("삭제하시겠습니까?") 후 POST 요청
- 댓글 입력 오류 시 상단에 flash 메시지 표시
- [목록으로] → /posts

## S-05 게시글 작성 / S-06 게시글 수정
- 같은 템플릿(post/form.html)을 공유
  - 작성: 제목 "글쓰기", 버튼 [등록], action = POST /posts
  - 수정: 제목 "글 수정", 버튼 [수정], action = POST /posts/{id}/edit, 기존 값 채움
- 입력: 제목(한 줄), 본문(textarea 15줄)
- 각 입력란 아래 오류 메시지 영역
- 버튼: [등록|수정] [취소] (취소 시 작성은 목록, 수정은 상세로)

## E-01 에러 페이지 (templates/error/403.html, 404.html, 500.html)
- 403: "접근 권한이 없습니다"
- 404: "요청한 페이지를 찾을 수 없습니다"
- 500: "일시적인 오류가 발생했습니다"
- 공통: [홈으로] 버튼

## 화면 이동 흐름
S-01 목록 --제목 클릭--> S-04 상세
S-01 목록 --[글쓰기]--> S-05 작성 --등록 성공--> S-04 상세
S-04 상세 --[수정]--> S-06 수정 --수정 성공--> S-04 상세
S-04 상세 --[삭제] 성공--> S-01 목록
S-04 상세 --[목록으로]--> S-01 목록
헤더 [회원가입] --> S-02 회원가입 --가입 성공--> S-03 로그인 (?joined)
헤더 [로그인] --> S-03 로그인 --로그인 성공--> S-01
로그인 필요 페이지 (비로그인 접근) --> S-03 로그인 (?redirectURL=원래주소) --로그인 성공--> 원래 페이지
헤더 [로그아웃] (POST) --> 세션 종료 --> S-01
