# PRD: SimpleBoard (로그인 기반 간단 게시판)

## 1. 목적
회원가입한 사용자가 글과 댓글을 남길 수 있는 간단한 게시판을 만든다.
Spring Boot + JdbcTemplate + MySQL로 SQL을 직접 다루며 웹 애플리케이션 전체 흐름을 익히는 학습용 프로젝트이며, "끝까지 완성"하는 것이 1차 목표다.

## 2. 대상 사용자
- 소규모 동아리/스터디 구성원 (동시 사용자 수십 명 수준)

## 3. 사용자 역할
| 역할 | 설명 | 가능한 일 |
|---|---|---|
| 비회원 (GUEST) | 로그인하지 않은 방문자 | 회원가입, 로그인 |
| 회원 (USER) | 로그인한 사용자 | 글 보기, 글 작성, 본인 글 수정/삭제, 댓글 작성, 본인 댓글 삭제 |

관리자(ADMIN) 역할은 이번 MVP에서 만들지 않는다.

## 4. MVP 범위 (이번에 만드는 것)
- 회원가입 (이메일, 비밀번호, 닉네임)
- 회원정보 수정
- 회원 탈퇴
- 로그인 / 로그아웃 (HttpSession 직접 구현, Spring Security 미사용)
- 게시글 목록 (최신순, 페이지당 10개)
- 게시글 상세 (조회수 포함)
- 게시글 작성 / 수정 / 삭제 (본인만 수정·삭제) / 파일/이미지 첨부, 
- 댓글 작성 / 삭제 (본인만 삭제)

## 5. 범위 밖 (이번에 만들지 않는 것)
- 관리자 기능, 비밀번호 찾기
- 소셜 로그인, 이메일 인증
- 에디터(WYSIWYG)
- 검색, 좋아요, 대댓글, 알림
- REST API / 별도 프론트엔드 (서버 렌더링 Thymeleaf만 사용)
- JPA / MyBatis 등 다른 데이터 접근 기술 (JdbcTemplate만 사용)
- Spring Security (로그인/권한은 HttpSession + Interceptor로 직접 구현)
- CSRF 토큰 (대신 SameSite 세션 쿠키 + 상태 변경 요청은 POST로만 처리)
- 자동 로그인(Remember me)

위 항목은 요청 없이 구현하지 않는다.

## 6. 성공 기준
- 비회원 → 회원가입 → 로그인 → 글 작성 → 수정 → 댓글 → 삭제 → 로그아웃 흐름이 에러 없이 동작한다.
- 다른 사람의 글/댓글은 URL을 직접 입력해도 수정·삭제할 수 없다.
- 로컬 MySQL에 데이터가 저장되고, 애플리케이션을 재시작해도 데이터가 유지된다.
- `./gradlew test` 가 모두 통과한다.

## 7. 비기능 요구사항
- 세션에는 비밀번호를 저장하지 않는다. 세션 유지시간은 로그아웃하거나 브라우저를 닫을때까지.
- DB 접속 비밀번호는 코드나 git에 올리지 않는다. (application.yaml은 git 제외, 별도 배포)
- 모든 입력값은 서버에서 검증하고, 오류 메시지를 화면에 보여준다.
- 에러 발생 시 스택트레이스 대신 사용자용 에러 페이지를 보여준다.
- PC와 모바일 브라우저에서 깨지지 않는 기본 반응형 화면
